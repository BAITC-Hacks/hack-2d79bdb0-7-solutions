# Промпт для ИИ Асанали

Скопируй текст ниже в ИИ, которому доступен терминал и локальная копия репозитория.

---

Я Асанали, работаю с Мадияром в команде 7-Solutions на HackAlem AI. Репозиторий: https://github.com/BAITC-Hacks/hack-2d79bdb0-7-solutions. Кейс «Электрокомплект»: автоматический расчёт заказов поставщикам для пополнения склада.

Продолжай существующий проект, не создавай его заново. Клонируй репозиторий или безопасно обнови имеющуюся копию, сохранив незакоммиченные изменения. Сначала прочитай AGENTS.md, HANDOFF.md, README.md, DATA_CONTRACT.md, TASKS.md, CONTRIBUTING.md и DEMO.md. Осмотри код и актуальные ветки/PR.

Запусти `python -m unittest discover -s tests -v`, затем приложение `python server.py` и проверь синтетическое демо. В исходной версии было 20 проходящих тестов; не считай это гарантией для текущей версии. Реальные ZIP с данными передаются отдельно; не подменяй их синтетикой без явной пометки.

Моя начальная область — данные и оценка прогноза. Если DATA-1 свободна, создай ветку `asanali/data-reconciliation`, отметь задачу в TASKS.md и реализуй отчёт сопоставимости месячных продаж с динамикой по SKU/месяцу с понятными расхождениями и тестами. Если нужных реальных файлов пока нет, подготовь проверяемую логику и синтетические тесты и явно назови недостающие входы. Не заявляй проверку реальных данных, которой не было.

Не меняй одновременно интерфейс, над которым может работать Мадияр. Сохрани контракт API и рабочий запуск. Не выдумывай клиентов, дни stockout, текущие остатки и экономию; в предоставленных источниках есть ограничения, описанные в HANDOFF.md. Не отправляй заказы поставщикам.

После завершения проверь затронутый путь, обнови HANDOFF.md и TASKS.md, закоммить изменения в своей ветке и отправь её в этот репозиторий. Открой PR в main с описанием изменения и результатов тестов; не выполняй force push и не перезаписывай изменения Мадияра. Дай мне короткий отчёт, ссылку на PR и следующий шаг.
