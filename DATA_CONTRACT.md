# Контракт и ограничения данных

Источник задачи: предоставленный командой документ «HackAlem AI — Автоматизация формирования заказов поставщикам», кейс ТОО «Электрокомплект». Оригинальные коммерческие файлы не включены в исходники репозитория.

| Источник | Systeme Electric | IEK | Как используется |
|---|---|---|---|
| Динамика продаж | 77 314 строк листа с заголовком | 171 605 строк листа с заголовком | Положительные расходные накладные, выявление выбросов |
| Месячные продажи | 2024–2026, код 1С + артикул | 2024–2026, код 1С | Основной временной ряд количества |
| Месячные остатки | Начальные/месячные снимки | Явно начальные остатки | Предварительный остаток, не дневной stockout |
| MOQ | Кратность | Минимальная отгрузка | Разные ограничения заказа |
| Товары в пути | Свободный остаток, категория, рост, поставка 24.09 | Партии с датами до 30.09, 01.10, 10.10, 15.10 | Остатки/ETA; фильтрация по горизонту |
| Сезонность | Выручка по месяцам | Выручка по месяцам | Приближение сезонного профиля поставщика |

Количество строк листа не равно числу продаж или товаров: есть заголовки, пустые строки, корректировки и другие документы. Проверенная сумма положительных строк расходных накладных двух поставщиков — 248 467.

## Нужно уточнить у владельца кейса

1. Ежедневные интервалы отсутствия товара или движения, достаточные для их восстановления.
2. Обезличенный ID клиента в истории продаж; номер документа не является ID клиента.
3. Актуальные свободные остатки IEK и дата их актуальности.
4. Сроки поставки и периодичность заказов по поставщикам/категориям.
5. Семантика кодов категорий и бизнес-политика страхового запаса.
6. Правила трактовки пустых продаж и отрицательных документов.
7. Коэффициенты пересчёта закупочных единиц в складские (например, бухта → метры).
8. Схема CSV/Excel для импорта в конкретную конфигурацию 1С.

Полный нормализованный формат и пример находятся в README.md. При отсутствии этих данных интерфейс и документация должны явно сохранять ограничения; запрещено выдавать синтетические поля за факты партнёра.
